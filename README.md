## Nogent la Street

Nogent la street est un petit jeu amateur développé en vibe coding sur le thème de la ville de Nogent-le-Rotrou (28) pour intégrer sur le site [WikiPerche](@https://wikiperche.fr).

L'objectif est de deviner une rue de la ville chaque jour à partir de 3 indices maximum. Une nouvelle rue est proposée quotidiennement à midi.

![Logo Nogent la street](https://i.ibb.co/tPFLhKWm/logo-nogent-la-street.png)

### Stack technique

Ce jeu utilise le framework Next.js proposé et hébergé par Vercel.app.

La base de données SQL contenant les rues est hébergée par Supabase.com.

### Droits d'utilisation

Vous êtes libre de réutiliser le présent code pour tout autre projet similaire.
